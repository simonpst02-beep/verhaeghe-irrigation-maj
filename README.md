# Verhaeghe Irrigation – distribution

Application Android réservée aux membres Verhaeghe Irrigation (code d'activation personnel demandé au premier lancement).

- Dernière version : [Verhaeghe-Irrigation.apk](https://github.com/simonpst02-beep/verhaeghe-irrigation-maj/releases/download/derniere-version/Verhaeghe-Irrigation.apk)

Ce dépôt est rempli automatiquement à chaque nouvelle version. `licences.json` ne contient que des empreintes des codes, jamais les codes eux-mêmes.
